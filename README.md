# 气象干旱与农业干旱的耦合关系及其对 GPP 的影响

R 语言综合练习。用 VPD 表征气象干旱、用 0–7 cm 表层土壤水分（SM1）表征农业干旱，
构建标准化干旱指数，用滑动相关识别二者的同步 / 不同步时段，并比较两类时段下
GPP（总初级生产力）对干旱的响应差异。

## 数据

| 文件 | 内容 | 说明 |
|---|---|---|
| `ERA5L_TWSA.csv` | 气象与水文变量（VPD、SM1 等） | 8 天尺度，2002-04-15 ~ 2022-12-11 |
| `GPP_anomaly.csv` | GPP 异常值 | 8 天尺度，2003-01-01 ~ 2015-12-27 |

两表按日期内连接，分析期为 **2003-01-01 至 2015-12-27，共 598 个 8 天时段**，单站点。

## 方法

1. **标准化干旱指数**：按排名计算经验分位，再做正态分位数变换
   `z = Φ⁻¹[(rank − 0.5) / n]`；气象干旱指数 `MD = +z(VPD)`，农业干旱指数 `AD = −z(SM1)`，
   指数越大越干，阈值取 1（约 84 分位）。
2. **干旱事件三要素**：连续超阈值时段为一次事件；强度 = 事件内指数均值，
   持续时间 = 时段数 × 8 天，烈度 = Σ(指数 − 1)。
3. **滑动相关**：24 期（192 天）窗口逐期滑动，计算 MD 与 AD 的 Pearson 相关系数；
   `r ≥ 0.5` 记为同步，否则记为弱耦合（不同步）。
4. **GPP 响应**：分两组计算 GPP 与两种干旱指数的相关系数、回归斜率、
   干旱期（AD > 1）与非干旱期的 GPP 均值差。

## 主要结果

| 指标 | 数值 |
|---|---|
| 两指数整体相关 | r = 0.60 |
| 干旱时段 | 气象 95 个、农业 95 个，其中同时干旱 42 个 |
| 干旱事件 | 气象 38 次、农业 36 次 |
| 同步 / 弱耦合时段 | 71.7% / 28.3% |
| GPP 与 AD 的相关 | 同步 −0.195，弱耦合 −0.295 |
| GPP 对 AD 的斜率 | 同步 −0.189，弱耦合 −0.339（约 1.8 倍） |

弱耦合时段的 GPP 对干旱更敏感，但两组差异未通过显著性检验（Fisher z p ≈ 0.25，
交互项 p ≈ 0.14），且弱耦合组仅含 18 个干旱样本，结论应表述为“方向明确、证据有限”。

## 文件说明

figs/                    输出图件（3 张）

## 运行方法

```r
# 在 RStudio 中打开本项目，工作目录设为项目根目录，然后：
source("drought_gpp_analysis.R")
```

或在命令行：

```bash
Rscript drought_gpp_analysis.R
```

脚本会自动创建 `figs/` 与 `results/` 并写入结果，重复运行会覆盖同名文件。

## 已知局限

- 标准化按全序列排名，未去除季节循环，可能把“季节性偏高”识别为“干旱异常”；
- 事件识别未设最短历时与间隔合并，38 次气象干旱中有 19 次仅持续 1 期；
- 仅使用表层土壤水分，未考虑深层储水；
- 时间序列自相关较强，有效样本量小于名义样本量。
